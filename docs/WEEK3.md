# Осы аптада не жазылды

HashService файлды 8192 байттық бөліктермен оқып, SHA-256 қайтарады.
DirectoryScanner қалтаны ішкі қалталарымен бірге қарап, FileRecord тізімін жасайды.
IntegrityService екі күйді салыстырып, оқиға не бос нәтиже қайтарады.
DatabaseManager кестелер мен қосылымды дайындайды; FileRepository SQL сұрауларын орындайды.
EventLogger файлға, FileRepository базаға оқиғаларды жазады; AlertService консольге шығарады.
DirectoryWatcher filesystem хабарларын қабылдайды және толық қайта сканерлеумен нәтижені нақтылайды.
Main баптауларды оқып, init/check/watch режимдерін байланыстырады.

Модель кластары мен MonitorConfig сақталды. Қазіргі CLI Properties және Path-ты Main ішінде қолданады;
MonitorConfig болашақ рефакторинг үшін қалдырылған, іске қосу жолында пайдаланылмайды.

Қорғауда: «Бастапқы хэшті базаға сақтап, файлды өзгерткенде жаңа хэшпен салыстырамыз.
Бақылау кезінде алдыңғы snapshot жаңарады, бірақ сенімді baseline өзгермейді.
Жаңа файл, өзгерген файл және жойылған файл туралы оқиғалар консольге, журналға және базаға түседі».
