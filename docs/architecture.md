# File Integrity Monitor архитектурасы

## 2-аптаның мақсаты

Жобаны пакеттерге бөлу, негізгі кластар мен әдістердің
қаңқасын дайындау және Main арқылы объектілердің құрылуын тексеру.

## Пакеттер

| Пакет | Міндеті |
|---|---|
| config | Бағдарлама баптауларын сақтау |
| model | Файл және оқиға мәліметтерін сипаттау |
| service | Сканерлеу, бақылау және тұтастықты тексеру |
| repository | SQLite деректер базасымен жұмыс |
| notification | Ескертулер мен оқиғалар журналы |

## Негізгі кластар

- Main — бағдарламаның кіру нүктесі.
- MonitorConfig — бақыланатын қалта мен база жолын сақтайды.
- FileRecord — файл жолы, хэші, көлемі және өзгеру уақытын сақтайды.
- FileEvent — өзгеріс туралы мәліметті сақтайды.
- EventType — CREATED, MODIFIED, DELETED оқиға түрлерін анықтайды.
- HashService — SHA-256 есептеуге арналған.
- DirectoryScanner — каталогтағы файлдарды сканерлеуге арналған.
- DirectoryWatcher — каталог өзгерістерін бақылауға арналған.
- IntegrityService — бастапқы және қазіргі файл күйін салыстыруға арналған.
- DatabaseManager — базаға қосылу және кестелерді дайындауға арналған.
- FileRepository — файл жазбаларын сақтау және іздеуге арналған.
- AlertService — пайдаланушыға ескерту көрсетуге арналған.
- EventLogger — оқиғаларды журналға жазуға арналған.

## Қазіргі байланыстар

Main MonitorConfig және HashService объектілерін жасайды.
HashService DirectoryScanner конструкторына беріледі.
DatabaseManager FileRepository конструкторына беріледі.

Қалған компоненттерді біріктіру келесі кезеңдерде орындалады.

## Баптау файлы

src/main/resources/application.properties:

- monitor.directory — бақыланатын қалта.
- database.path — SQLite базасының жолы.
- log.path — журнал файлының жолы.

Баптау файлын оқу әзірге іске асырылмаған.
Main ішіндегі жолдар уақытша кодта берілген.

## Қазіргі күйі

Деректер модельдері мен класс қаңқалары дайын.
Main іске қосылып, объектілер туралы ақпаратты консольге шығарады.

Хэштеу, сканерлеу, мониторинг, базаға қосылу,
салыстыру және журналға жазу әлі іске асырылмаған.
Олардың әдістері UnsupportedOperationException тастайды.

## Қауіпсіздік шешімі

База мен журнал бақыланатын қалтадан бөлек орналасады.
Анықталған өзгеріс автоматты түрде сенімді күйге айналмайды.
Сенімді бастапқы күйді жаңарту бөлек мақұлдауды талап етеді.
